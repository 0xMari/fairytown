# Fairytown

Procedural fairy-world starter built with Three.js and Vite and Codex support for repetitive task and tidying up the code.

## For now

- Three explorable biomes (medow, crystal and forest/mushroom kinkdom).
- Infinite-ish chunk loading around the camera
- Fairy-style flying controls.
- Assets for trees, rocks, mushrooms, crystals, flowers, lanterns, and ambient particles.
- Day/night cycle
- placeholder loading page -> will customize later

## To do

## Included External Meadow Grass

The meadow biome used to use grass assets adapted from [thebenezer/FluffyGrass](https://github.com/thebenezer/FluffyGrass) via files in [`public/fluffy-grass`](./public/fluffy-grass).
Meadow-specific setup is grouped in [`src/world/medow`](./src/world/medow).
